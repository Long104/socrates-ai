### Problem
Chat copy exposed machinery: "Let's start with Supporting View A", "All assumptions examined", "The Middle Way has emerged at the bottom of the graph." Felt like a guided worksheet, not a dialogue.

### Solution: Hybrid (#3)
Graph reveals on its own timeline. Chat never references it or labels. Feels like pure Socratic sparring that happens to have visuals emerging alongside.

### Changes
**prompts.ts:**
- DECONSTRUCT: "You are Socrates. You speak like him — short, sharp, never explaining your method."
- REFLECT: "You never explain what you're doing. You just ask."
- SYNTHESIZE: "Speak the Middle Way — one sentence that holds BOTH truths they discovered. No second person. No 'You'. Speak it as a fact."

**page.tsx:**
- Removed all "View A/B" labels
- Removed "Let's start with", "Let's move to the next assumption"
- Removed "All assumptions examined. The Middle Way has emerged..."
- Loading message: "..." instead of "Analyzing your belief structure..."
- Chat now just asks the question. Graph reveals silently.

### Result
Build green. Flow: user types belief → AI asks sharp question → graph reveals assumption → user answers → AI validates/counters → repeat → Middle Way appears as final line, spoken as bare truth.
